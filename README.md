# FRDLINK

个人博客友链（友情链接）展示页。纯静态实现，无需后端即可部署到任意静态托管（GitHub Pages、Vercel、自有服务器等）。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面主体：友链卡片展示、按年份筛选、关键词搜索、在线状态检测、友链申请表单 |
| `links.js` | 友链数据（名称、网址、简介、头像、加入年份），新增友链只需在此追加条目 |
| `favicon.ico` | 站点图标 |
| `links.js.bak` | 数据修改前的备份（确认无误后可删除） |

## 使用说明

1. **修改友链数据**：编辑 `links.js`，按现有格式追加/删除条目。字段说明：
   - `name`：站点名称
   - `url`：站点地址（建议 https）
   - `desc`：站点简介
   - `avatar`：站点头像图片 URL（加载失败会自动显示占位图）
   - `joinYear`：加入年份（用于年份筛选标签）
2. **站点配置**：编辑 `index.html` 顶部的「站点配置」区块：
   - `API_KEY` / `PROXY_API`：站点在线状态检测接口的密钥与地址
   - `ADMIN_EMAIL`：接收友链申请的邮箱（**上线前必须替换**，否则邮件无法送达）
3. **本地预览**：直接用浏览器打开 `index.html`，或运行 `npx serve .` 启动本地服务。
4. **部署**：将本目录所有文件上传到任意静态托管即可。

## 安全提示

- 页面为纯静态站点，`API_KEY` 会明文暴露在前端源码中。这是静态站直连第三方检测接口的固有限制；若该接口有配额或费用，请改为服务端代理转发（前端只调用不含 key 的接口）。
- 外部链接已统一添加 `rel="noopener noreferrer"`，防止反向 tabnabbing。

## 功能特性

- 友链卡片网格展示（头像懒加载 + 加载失败占位图）
- 按年份标签筛选、关键词实时搜索（250ms 防抖）
- 站点在线状态检测（10 秒超时、20 分钟本地缓存、失败与失联状态区分）
- 友链申请表单：URL/邮箱格式校验，一键唤起邮件客户端发送申请
- 标签支持键盘方向键切换（无障碍友好）
